成员清单
index.cjs: 复用安装流程真实路径隔离，私有环境启动与停止，按 server/cloudflare 模式组装发布器、阅读和公众号服务
http.cjs: 同源静态入口、独立阅读路由和 Bearer 鉴权发布/公众号路由，业务错误不泄露底层响应
reader.cjs: 仅已提交成功批次验密、限速与限时图片授权，持久化失败时关闭正文访问，复用共用图片改写保持代码示例
store.cjs: 写入前拒绝源码真实路径及符号链接别名；内容完整性、互斥发布和成功指针；提交失败立即回滚并释放互斥，磁盘持续不可写时保留内存失败状态，重启恢复中断
publisher.cjs: 历史外部发布命令适配，复用 web 的内容契约
local-publisher.cjs: 原稿与图片字节形成内容版本；共用构建事务，可选云部署成功后切换本机产物，失败保留旧站
cloudflare-publisher.cjs: Wrangler 配置与发布适配，日志位于私有配置目录；版本隔离私有 R2 对象先于公开部署，密码只保留派生值
static.cjs: 以 BatchStore 已提交记录选择静态版本，与受保护阅读保持一致；拒绝路径/符号链接逃逸，读盘失败或断开关闭文件流
wechat-render.cjs: Markdown 内联排版、代码/表格和 MathJax 公式图片，行内代码转义；图片占位符只在 img src 内映射
wechat-api.cjs: 官方账号 token/图片/草稿请求，可配置接口地址；HTTP 5xx 和异常成功响应归为结果不明，不发表或群发
wechat.cjs: 预览冻结与草稿保存事务，账号隔离、图片映射和幂等更新；外部结果不明时持久阻止重复新增

依赖方向：HTTP → 事务服务 → 注入适配器；公众号渲染与官方账号配置解耦，账号留空时仍可预览。博客和公众号成功记录互不影响。
[PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md
