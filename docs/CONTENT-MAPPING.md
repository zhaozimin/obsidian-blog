# 内容和目录映射

Obsidian 是唯一内容真源。上传当前目录树、Markdown、栏目配置及引用附件的完整快照；两种部署目标共用 `web/scripts/content-contract.cjs`。

## 栏目和分类

根目录 `blog-V3` 默认包含 `1.首页`、`2.深度长文`、`3.阅读思考`、`4.产品列表`、`5.关于` 五个已声明栏目，`6.附件` 保存照片。

栏目 `_栏目.md` 声明稳定 `id/kind`，文件夹决定栏目名与顺序。改名保留 `id/kind`，上传更新前端导航。未声明的顶级目录不能自动获得展示类型；模板保留基础五栏目。

文章子目录决定分类，如 `2.深度长文/效率工具/文章.md` 属于“效率工具”。移动改变分类，改文件名不改 `id`。重复身份、缺失声明或无效字段阻止发布。

## 首页和站点

`1.首页/站点设置.md`：网站名、作者、页脚、RSS、备案等属性；浏览器图标取网站名称首字，空站使用通用书页图形。`1.首页/home.md`：标题、介绍、背景、头像、社交链接和 SEO。

配置笔记主要填写 YAML 属性，不进入文章列表。空字段不补作者个人信息；开始添加文章时必须填写名称与作者。详细字段见 [web/CONTENT.md](../web/CONTENT.md)。

## 文章

控制台“新建文章”选择栏目、标题和可选分类，生成稳定 UUID、日期和对应字段：

```markdown
---
id: 由插件生成并保持不变
title: 我的文章
date: 2026-10-03
description: 文章简介
image: "[[封面.png]]"
tags: []
---

Markdown 正文。
```

支持代码、表格、图片和常用 LaTeX。`subtitle/link/password` 可选；书籍还可填作者、出版社、ISBN、评分、豆瓣链接和阅读日期，产品可填价格、链接与视频地址。以模板和内容契约为准。

## 图片和保护

照片放 `6.附件`，用 `![[图片.png]]` 或标准 Markdown 引用，封面写 `image`。只上传引用附件，不把全部附件当公开素材。重复文件名会阻止上传。

`password` 文章公开标题等元数据，正文和明文密码不进入公开快照。没有被公开内容引用的正文图片也不公开；封面、首页或共享图片属于公开资源。服务器用 Node 验密，Cloudflare 用私有 R2 + Worker 验密。网站密码保护不自动延伸到公众号。

## 同步

上传前检查清单，删除额外确认。成功快照替换列表，旧名和删除的笔记不产生额外文章；失败保持上份成功快照。私有历史用于恢复，不进入网站栏目。更换目标、恢复或迁移后从插件重新发布完整博客。

`控制台`、`使用说明`、`发布配置`、`.obsidian` 和 `CLAUDE.md` 不作为文章。公众号样式来自 `发布配置/公众号排版.json`，当前 `{}`。
