## 公众号接口验证的边界

模拟服务验证了封面与正文图片上传、只新增草稿、相同内容不重复新增、修改后更新同一草稿、服务重启后保留关联，以及上传结果未知时暂停盲目重试。没有配置账号时，原生插件可以预览，保存时会明确提示账号未配置。

真实公众号的草稿接口权限、IP 白名单、实际图片处理与手机排版尚未验收。正式公众号风格模板尚未提供，基础排版不能视为最终字体、字号和间距。后续填入服务器私有配置，再用一篇测试文章完成真实草稿箱验收，不发表或群发。

Docker、Nginx 与 systemd 提供部署示例；本机没有可用 Docker 服务，本次没有验证容器启动或公网部署。GitHub 上传由所有者稍后安排。
