# 验证范围

运行 `npm run check`：插件/服务行为测试、公众号模拟接口、Cloudflare Worker 行为、前端内容契约、TypeScript、插件及空网站构建、公开文件检查和 Wrangler dry-run。

公众号模拟验证必须覆盖：无账号预览、封面和正文图片上传、代码/表格/两类公式、只创建草稿、重复保存不新增、修改更新、重启后保留映射、未知网络结果暂停新增、鉴权与错误隐藏。

本机博客验证：新空库安装、插件单独启用、完整快照与引用图片上传、目录改名后栏目名称更新、密码正文不出现在公开 JSON/RSS、失败保留上版。运行数据必须只来自合成测试内容。

原生 Obsidian 验证：打开独立测试库，检查控制台按钮、新建笔记、公众号预览与账号未配置提示；不得修改正式笔记库连接或上传测试文章到正式博客。

Cloudflare 验证：加盐密码不等于明文；同源、限速、图片签名、过期和版本失效；私有上传先于公开部署，失败保留本机旧版。Wrangler dry-run 验证真实配置；本机 Worker/R2 模拟器验证运行协议。两者不等于真实云部署。接账号后核对网址、版本、公开/密码页面和桶权限，再清理合成内容。

未来真实公众号验收：填写私有账号配置、权限与 IP 白名单后，将一篇测试文章保存到草稿箱，检查桌面及手机预览中的代码、表格、公式和图片。不发表或群发。正式公众号风格模板尚未定义，当前不作为样式验收结论。
