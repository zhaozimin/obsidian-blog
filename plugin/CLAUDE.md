# plugin/

成员清单
main.js: Obsidian 生命周期与装配；初始化注册置顶复选框与同步互斥，常驻状态栏保留上传进度和结果，重载恢复成功记录或中断任务；中控台、模板、图片、自动排版与排版预览（settings.typeset）的设置默认值，写入四个内置模板不覆盖已有
collector.js: 拒绝非布尔置顶字段，五栏目递归扫描和 marked 语法树图片收集，引用式图片归一为站点路径，保留分类路径，用 SHA-256 对实际上传字节建立快照；%%注释%% 在采图前剥离
client.js: requestUrl 网络边界，HTTPS 地址规范、鉴权与异步发布轮询，错误只映射为可操作提示
ui.js: 变更清单、删除二次确认、服务器阅读保护说明与设置面板（博客 / 写作 / 排版预览 / 公众号四组），连接密钥遮蔽且不呈现底层握手
templates.js: 空栏目配置；四类写作模板以库内「模板」文件夹为准、缺失退回内置，字段说明与例子住在 %% 注释里；新建只填 id/title/date（本地日期），不执行脚本
authoring.js: 写作入口，替代 Buttons + QuickAdd + Templater：blog-button 中控台按钮按栏目稳定 id 进新建（也能触发上传、公众号预览、排版预览），弹窗选已有分类或新建分类，同名直接打开不覆盖；右键新建到栏目目录的空笔记套模板，代填的标题跟着改名走
images.js: 替代 Image Converter + Paste image rename：任何进库的图片都先转 WebP、再弹窗请作者起名（建议名取有意义的原名，截图类取笔记名，全库重名当场拦下），然后存进附件目录；编辑器里粘贴/拖入的由插件接管，链接每张独占一行插入，从文件列表或访达进库的在新建事件里补问名字、挪进附件、链接随改名更新；动图、矢量图、转完更大与解不开的格式保持原格式
format.js: 替代 Linter 的时机层，照 ziminOS Pro 的编辑欠账：正开着的那一篇不动，改过的笔记离开时整理，没开着的防抖整理；先存盘再 vault.process 并保住滚动，再入锁兜底；规则在 shared/typeset/format
wechat.js: 当前文章的 Wiki/标准及引用式图片通过代码隔离和语法树采集；排版参数来自笔记库配置，为空时取排版预览选中风格的同名 7 键，草稿与预览同一组字号行距配色；%%注释%% 先剥离
wechat-ui.js: 冻结预览和明确草稿保存，说明这份草稿用的是哪套排版参数，显示独立的公众号结果
styles.css: 发布确认布局、状态栏右端常驻状态、中控台整宽按钮、图片起名窗口与排版预览外框（pb- 前缀，隐藏类收在视图内），复用 Obsidian 主题变量
typeset/: 排版预览（6 文件：index 控制器、preview-view、device-frame、devices、compose、normalize-modal），并入原排版预览插件

扫描器不访问服务器；客户端不读笔记库；主入口只编排状态，UI 只提交用户选择；写作模块只动作者正在新建或已离开的笔记；排版预览只读当前笔记，复制与标点规范化由作者按下才发生。

[PROTOCOL]: 变更时更新此头部，然后检查 CLAUDE.md

新发布批次携带栏目身份与原始目录；_栏目.md 保存展示配置，目录改名进入 catalog 快照，不以中文名称推断类型。

本轮契约：目录改名保持身份、栏目清单和笔记声明一致，配置不进入文章列表；重复初始化不增加文章，未声明目录停止发布。站点 SEO 与 manifest 从同一快照生成。
