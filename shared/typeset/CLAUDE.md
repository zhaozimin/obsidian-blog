# shared/typeset/
> L2 | 父级: ../CLAUDE.md

排版的纯函数层：不依赖 Obsidian、DOM 或 Node API，同输入同输出，插件与服务端都能直接引用。
一条规则只住一个地方：空白（中英文空格、连续空格、空行、行尾）归 format，标点归 normalize；字符表 CJK 只在 format 定义一次。

成员清单
format.cjs: 空白排版规则，照 ziminOS Pro 的 markdownStyle 写成——中英文、数字之间恰好一个空格，连续半角空格收成一个，相邻文字行分段、段间一个空行，标题/列表/引用/表格/代码/分隔线/注释块上下留空行；按读者看见的字决定补不补空格，双链、链接、代码、网址、标签、HTML、公式、注释与属性区内部不动；全角空格与行尾两空格的硬换行保留；幂等是设计前提，自动整理靠它断开「写盘 → 再整理」的环
parse.cjs: 预览渲染的语法地基，Obsidian Markdown 子集解析，所有块带全文行号（嵌套块保持全文坐标），标题去状态 emoji 与 MOC- 前缀，%%注释%% 保留换行剥离
render.cjs: BaseRenderer 骨架 + WeChatRenderer（全内联样式、悬挂缩进列表、外链转文末注、分隔符居中）+ XRenderer（官方格式子集、标题两级映射、图片占位）；新增平台继承基类，不改已有渲染器
themes.cjs: 素 / 墨 / 白衬衫三套公众号风格（风格真源），带色浅底一律半透明色相（深色算法实测结论）；前 7 键与服务端公众号排版配置同名，草稿据此沿用预览风格
normalize.cjs: 标点规范化（手动、先确认再改）：中文语境全角标点、括号、省略号、破折号、成对引号、加粗末尾标点移出星号；尊重“”「」双体系与 U+3000，压平的多行原文只提醒；只替换行内文字，不增删行
diagnose.cjs: 结构体检（加粗密度、多卡引用块、无图图注、悬空引用、平台备注、残留按钮字）与统一字数口径；长段与无标题区交给视图实测
