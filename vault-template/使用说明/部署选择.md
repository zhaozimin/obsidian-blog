# 部署选择

完整源码与教程：https://github.com/zhaozimin/obsidian-blog

- 有服务器：让 AI 按仓库 docs/DEPLOY-SERVER.md 通过自己的 SSH 部署；插件连接自己的 HTTPS 网站。
- 没有服务器：让 AI 按 docs/DEPLOY-CLOUDFLARE.md 在电脑运行本机服务并上传 Cloudflare；插件连接 http://127.0.0.1:3002。已上传网站不依赖电脑保持开机，下一次上传需启动本机服务。

可直接复制 README 中的 AI 部署提示词。全公开文章不要求 R2，密码文章使用私有 R2；公众号账号可稍后接入，排版目前为空。
