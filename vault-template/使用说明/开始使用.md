# 开始使用

这是空白模板，没有示例文章或个人照片。只需要 Blog Publisher 一个社区插件。

1. 部署仓库中的服务端与网站，或按仓库 README 在本机启动。
2. 启用 Blog Publisher，在设置中填写发布地址和访问密钥。
3. 打开发布控制台，点击栏目按钮，输入标题、选分类，笔记会套上「模板」文件夹里的模板。
4. 模板顶部的 %% 填写说明 %% 只在编辑时可见，发布时自动去掉；模板可以直接改。
5. 图片直接拖进或粘贴进笔记：先转成 WebP，再请你起名字，存进 blog-V3/6.附件；从文件列表或访达放进笔记库的图片也会补问名字。
6. 写完切到别的笔记时，插件会自动整理格式：中英文之间一个空格，段与段之间一个空行。
7. 填写首页、站点设置和栏目配置，点击“上传博客”，检查变更后确认。
8. 公众号：打开文章，运行“预览并上传当前文章到公众号草稿箱”。

本机连接配置与上传历史由插件私有保存，不要将插件 data.json 分享给其他人。
