# 微信公众号

当前目标为草稿箱，不直接发表或群发。公众号账号尚未配置时，仍能通过服务端预览。

正文支持标题、列表、引用、代码块、表格、行内公式 $E=mc^2$ 与独立公式 $$...$$。公式会在公众号版本中生成 PNG，原笔记保留 LaTeX。原始 HTML 作为文字显示；远程图片需要先保存到本地附件。动画图片当前取首帧。

## 文章属性

- image 或 wechatCover：本地封面；没有设置时使用正文首张图片。
- wechatAuthor：公众号署名（可选）。
- wechatDigest：摘要（可选，默认 description）。
- wechatSourceUrl：原文链接（可选）。
- wechatDraftId：已有的独立单篇草稿标识（可选，通常由服务端自动记录）。

## 排版

发布配置/公众号排版.json 目前为 {}，使用基础测试排版；正式写作风格稍后设置。可配置 fontSize、lineHeight、paragraphGap、headingSize、color、accent、fontFamily，详情见仓库 docs/WECHAT.md。

## 以后接入账号

在服务器私有配置中填写 WECHAT_APP_ID、WECHAT_APP_SECRET；添加服务器出口 IP 白名单并确认草稿接口权限，再重启服务。插件只填写服务地址与访问密钥。不要在聊天、文章、GitHub 中填写 AppSecret。

## 草稿与重试

重复保存同一版本不新增，修改后更新原独立草稿。如果草稿新增请求断线且结果不明，会暂停新增；先检查后台，将实际草稿标识填入 wechatDraftId，再重新预览。公众号真实版式需以后用你的账号在手机预览验收。
