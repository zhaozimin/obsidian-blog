# 博客设计约定

本站消费 [ui.zhaozimin.com](https://ui.zhaozimin.com/) 的「纸·墨·朱」冻结版本 **0.2.0**。上游是唯一设计系统来源，版本与 CSS 校验值记录在 `design-system.lock.json`，不在本站修改通用控件配方。

整体页面尺寸、功能入口、内容属性与呈现边界汇总在 [README 手册](README.md#整体设计纸墨朱与阅读秩序) 与同源的 [HTML 图文手册](docs/blog-handbook.html)。手册是项目文档，不是博客页面，不进入网站发布包。

- 纸白画布 `#F6F6F4`，墨色文字，朱色 `#A6402F` 用于当前导航和焦点。内容图片保留自己的颜色。导航字标末尾的点保留用户指定 `#eb533b`；页脚末尾的点使用主题朱色。页脚字标对齐 [zhaozimin.com](https://zhaozimin.com/)：`Inter, -apple-system, system-ui, sans-serif` 字体栈、800 字重、`clamp(22px, 2.25vw, 28px)` 字号（按后续要求缩小，使头像与文字协调）、1 倍行高、-.02em 字距，句点与姓名在同一基线上，不增加在线字体依赖。
- 按键、输入框、可点卡片及播放器复用 `zzm-btn`、`zzm-input`、`zzm-cardlink`、`zzm-video-play`；只在博客样式中安排尺寸与布局。
- 系统字体为主，间距及行高按 4pt / 8pt 网格。响应式容器最大 1296px，左右 48px 留白；手机 24px。
- 三个栏目采用用户确认的「图文分栏」介绍：列表容器最大 1120px（含留白），简介区独立居中、最大 800px，宽屏不继续拉宽；桌面最小高度 352px，左侧栏目名、主张、简介和主题，右侧固定 320px 的主题画面，间距 32px。760px 及以下自适应宽度、文字在上画面在下。长文用红色笔记构图，书籍用绿色封面/批注，产品用金色教程/资料组合；产品介绍的金色不改变免费卡片的中性规则。右侧保留推荐稿构图，书籍与产品从最新有图内容选择封面；空集合使用同尺寸文字构图，后续按用户提供的新图片样式与内容调整。CollectionHero 负责画面，site.ts 集中管理栏目文案；不把方案预览的切换器、调节面板或固定舞台高度带入网站。
- 栏目简介统一 24px 行高、48px 固定高度，单行文案同样预留第二行，超过两行显示省略；桌面与手机共用规则。三个栏目相同宽度下的文字区、标题、主张、简介和主题标签保持相同坐标，避免自动行数改变整体垂直居中的位置。
- 首页半身像铺满导航下方的整个上半区域，不设照片卡片和外围留白；作者介绍叠放在照片留白上，小屏文字移至顶部、按钮移至底部；手机两个按钮横向居中。更新区上方的满宽横线分隔上下内容，下方仅展示最近更新。首页与分类页的卡片占满内容宽度并居中，桌面三列、平板两列、手机一列；不足一行的卡片也居中排列。
- 卡片布局参考 [Dan Koe](https://thedankoe.com/)：封面置顶、标题与摘要在下方、阅读入口在底部。卡片与所有阅读页首图统一 16:9。图片不增加描边；正文图与详情封面统一12px圆角、柔和双层阴影，桌面悬停上浮2px且增强阴影，减少动态效果时关闭位移。深度长文、行者百书和产品详情的阅读页开头先显示独立的22px元信息栏，12px后进入等宽双栏：左侧标题、副标题、简介及相关操作，右侧封面，32px栏间距。封面仅与下方文字区垂直中心对齐，元信息不参与居中计算。760px及以下改为上下排列，无封面时保持完整文字宽度。下方文字区只保留标题44px单行、副标题28px单行、简介48px双行、按钮36px，各段间距12px；缺省按钮保留自身一行，超长文字省略。手机标题36px、副标题24px，其余高度保持。书籍作者/出版社放在按钮行右侧，单行超长省略，不再占用正文前独立一行；作者只消费按钮行剩余宽度、右侧留8px内边距，标签文字水平与垂直居中。分隔线两侧共用40px间距（手机28px），正文空行只分段不生成占位，连续文字软换行归入同段；常规正文网格16px块间距、标题前28px；深度长文通过显式data-post-type选择18px字号/1.9倍行高/.02em字距，720px居中限宽约39个汉字一行，段间24px、标题前40px（24px网格加16px）；手机17px/1.85倍行高、段间22px/标题前36px。段落、引用和列表共同继承正文参数，长文引用使用直立字形，列表标记按首行中心对齐；标题28/24/20px、行高40/36/32px，代码块13/24px和图注12/20px保持辅助层级，行内代码按正文.875em缩放。首个正文块无额外顶部外边距。图片图注距图8px，文件名URL编码只解码一次并去图片后缀，完整上传原名保留在悬停提示；豆瓣链接、产品访问与视频链接仍在左侧操作区。既有竖版图片仅作 CSS 裁切，后续更换横版图片即可适配。类型标识/阅读入口：长文红 #B84535、书籍绿 #287345、付费金 #946C0A，免费产品中性；经济学青绿、创业橙、工作流蓝、AI 紫，新分类按名称稳定生成颜色，分类独立于内容类型。
- 关于页介绍、头像与人生履历共用最大 960px 的居中容器（含两侧留白），在宽屏保持同一宽度，小屏自适应；内容不跟随全站 1296px 容器拉宽。故事默认显示两行摘要（手机三行），鼠标移入自动展开、移出恢复；点击或键盘可固定展开。
- 阅读页正文独立居中，左侧胶囊条形码与阅读进度保持原有交互，点击向右展开单列层级目录。所有标题按正文顺序从上到下连续排列、自然换行，取消章节分栏。关闭按钮固定在面板顶部，面板为导航和屏幕边缘留白；超长列表支持纵向滚动并隐藏滚动条，避免底部章节落在视口外。手机入口在左下，展开同一单列目录；点击入口、点外部或按 Esc 收起。
- 作者头像与半身像由首页元数据 heroImage/heroPortrait 指定，来自外部上传图片目录，不进入模板仓库。空照片使用图形占位，不请求虚构图片路径。
- 手机关于页用紧凑双栏，左侧 SITE 座右铭“保持真实，保持思考。”，右侧 88–128px 的头像；不显示原介绍文案与“从我的文字开始”按钮，下方直接接人生履历，点击展开故事的功能保留。
- 页脚删除「读一篇文章」与「了解我」快捷跳转及对应样式。手机作者信息在上，社交入口在下，最多五个一行并居中。底部版权与说明在左，两个备案号在右，左右各自竖排，窄屏缩紧底部字号；返回顶部距下边缘 80px，避开备案文字。桌面继续横排作者/社交、版权/备案。
- 页脚头像高度等于姓名行高 + 8px 间隔 + 20px 说明行高，保持上下边界等高。八个平台通过 Apple Lookup 核对 App Store ID 和开发者，使用商店的 512×512 原图。全部入口复用邮箱的 `zzm-btn zzm-btn--icon`，尺寸 36px，保留纸墨渐变/边框/阴影；图像完整显示为 30px，圆角 5px。默认 `grayscale(1)`、.65 透明度，鼠标悬停和键盘聚焦恢复原色及完整透明度。邮箱与 RSS 沿用功能图标。来源见 `public/social/CLAUDE.md`。
- 目录交互恢复依据：只读参考仓库 `CKlaozhao_V11` 的初始提交 `726141e`（2026-02-01），及 2026-01-09 快照中的竖向圆角胶囊；保留旧版左侧条形码、点击展开、层级线与进度，颜色仍消费纸墨令牌；按最新要求统一单列，超长列表滚动且不显示滚动条。
- 全站图片预览按原图挂载：遮罩淡入 300ms、图片放大入场 340ms，关闭淡出缩小 260ms；入场缩放与用户拖拽分层，关闭动画结束后才卸载。减少动态效果时动画缩至 1ms，不延迟退出。
- 原生 dialog 负责搜索和密码窗口的模态焦点。搜索结果包含标题、副标题、16:9 缩略图与高亮匹配句子；正文优先，只有标题/副标题/简介命中时明确标明来源，普通句子完整显示，超长句围绕关键词截取。索引保留可读正文与段落边界，图片路径/链接地址不参与匹配，类型仍使用红/绿/金色。上下键选择时保持当前结果可见，Enter 打开，Esc 收起。页面滚动和目录锚点不改写 HashRouter 的地址。旧版主题切换移除，以纸白界面保持此版本的设计一致性。

修改布局后检查对应组件 L3 与模块 CLAUDE.md；升级上游版本时同时更新冻结文件和锁定记录。

### 中文长文阅读依据

- [W3C《中文排版需求》](https://w3c.github.io/clreq/#line_gap)：行间空白通常为字号的50%–100%；本站1.9倍行高是实际内容的设计选择，不把行间空白误当CSS行高。
- [W3C 中文字距指南](https://www.w3.org/International/articles/styling/inline-space.zh-hans.html)：中文正文宜自然密排，本站只加.02em字距，以字号、行距和段间距提供主要阅读空间。沿用冻结的系统中文黑体字体栈，避免网络字体加载时跳动。
- [WCAG 1.4.8 视觉呈现](https://www.w3.org/WAI/WCAG22/Understanding/visual-presentation.html)：参考CJK每行不超过40个字形、避免强制两端对齐的阅读原则。
- [WCAG 1.4.12 文本间距](https://www.w3.org/WAI/WCAG22/Understanding/text-spacing.html)：1.5倍行高、2em段距、.12em字距、.16em词距是用户覆盖样式时的兼容测试参数，并非要求网站默认采用，也不据此宣称全站符合WCAG。
